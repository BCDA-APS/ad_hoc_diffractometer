zaxis — Z-Axis Four-Circle (Surface)#

Z-axis four-circle diffractometer for surface diffraction. The sample surface normal is parallel to the Z-axis. Sample and detector share an alpha base stage.

Walko (2016) designation: (S1D2)1

Coordinate basis: You (1999) (BASIS_YOU): vertical=+x, longitudinal=+y, lateral=+z.

Quick start#

import ad_hoc_diffractometer as ahd

g = ahd.presets.zaxis()
g.wavelength = 1.0  # Å
print(g.summary())

Diffraction modes#

Each mode is a ConstraintSet of 1 constraint (N − 3 = 1 for N = 4 DOF). Requires g.surface_normal = (h, k, l) — see Surface Geometry and the Reference Vector. See Work with Constraints and Diffraction Modes for the extras dict pattern.

zaxis#

ReferenceConstraint: surface normal aligned with the Z-axis; alpha directly equals the incidence angle β_in, gamma directly equals the exit angle β_out.

Computed

Z, delta, gamma

Constant during forward()

reflectivity#

ReferenceConstraint: symmetric reflection — alpha_i = beta_out (alpha = gamma).
