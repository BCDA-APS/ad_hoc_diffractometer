stage
=====

.. py:module:: ad_hoc_diffractometer.stage

.. autoapi-nested-parse::

   Import: ``ad_hoc_diffractometer.stage``

   A Stage represents one rotary axis of a diffractometer.  Its rotation axis
   is stored internally as a signed numpy array (the internal representation).
   The caller-facing +x/-z string notation is handled in axes.py.

.. py:class:: Stage(name: str, axis: ~numpy.ndarray, parent: str | None = None, role: str = 'sample', angle: float = 0.0, limits: tuple[float, float] = (-180.0, 180.0))

   .. container:: import-path

      Import: ``ad_hoc_diffractometer.stage.Stage``


   One rotary stage of a diffractometer.

   Each stage is characterised by:
     - a name (e.g. 'mu', 'eta', 'chi')
     - a rotation axis expressed as a signed Cartesian vector in the lab
       frame (e.g. +XHAT for right-handed vertical, -ZHAT for left-handed
       lateral).  Use axes.parse_axis() to construct this from the
       caller-facing notation.
     - a parent stage name (the stage on which this one sits), or None if
       it sits on the floor / fixed lab frame.

   The sign of the axis vector encodes handedness:
       +nHat  =>  right-handed rotation about nHat
       -nHat  =>  left-handed rotation about nHat

   :param name: Human-readable name for this stage (e.g. 'mu', 'S2-1').
   :type name: str
   :param axis: Signed rotation axis vector in the lab frame (internal representation).
                Construct from caller-facing notation using axes.parse_axis().
   :type axis: numpy.ndarray, shape (3,)
   :param parent: Name of the stage on which this stage is mounted, or None if it
                  sits directly on the lab frame (floor).
   :type parent: str or None
   :param role: 'sample' or 'detector', for bookkeeping.  Default is 'sample'.
   :type role: str, optional
   :param angle: Current angle setting in degrees.  Default is 0.0.
   :type angle: float, optional
   :param limits: (min_angle, max_angle) in degrees.  Default is (-180.0, 180.0).
                  Must satisfy min_angle < max_angle.
   :type limits: tuple of (float, float), optional

   :raises ValueError: If limits[0] >= limits[1].
