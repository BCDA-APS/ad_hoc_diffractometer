reference#

Import: ad_hoc_diffractometer.reference

Provides standalone functions for computing the physical pseudo-angles that appear in ReferenceConstraint conditions: incidence angle, exit angle, azimuthal angle ψ, and lab-frame azimuthal angle naz.

These functions require the geometry’s surface_normal or azimuthal_reference to be set before calling.

Functions#

incidence_angle()

Angle of incidence α_i between the incident beam and the sample surface.

exit_angle()

Angle of exit β_out between the diffracted beam and the sample surface.

psi_angle()

Azimuthal angle ψ of the reference vector n̂ about Q (You 1999, eq. 23).

naz_angle()

Azimuthal angle of n̂ projected onto the lab-frame horizontal plane.

Notes

All functions accept a geometry instance and an optional angles dict of motor angles (defaulting to the geometry’s current stage angles when None). They raise ValueError when the required reference vector is not set on the geometry.

References

  • You, J. Appl. Cryst. 32, 614-623 (1999), eqs. 10-11, 23.

  • Lohmeier & Vlieg, J. Appl. Cryst. 26, 706-716 (1993), §4.2.

Import: ad_hoc_diffractometer.reference.exit_angle

Compute the angle of exit β_out in degrees.

The angle between the diffracted beam and the sample surface. Positive when the diffracted beam exits through the front face.

Requires surface_normal to be set.

Parameters:

  • geometry (AdHocDiffractometer) – The diffractometer instance.

  • angles (dict[str, float] or None) – Motor angles in degrees. If None, the geometry’s current stage angles are used.

Returns:

Exit angle β_out in degrees.

Return type:

float

Raises:

ValueError – If geometry.surface_normal is None.

ad_hoc_diffractometer.reference.naz_angle(geometry: AdHocDiffractometer, angles: dict[str, float] | None = None) → float[source]#

Import: ad_hoc_diffractometer.reference.naz_angle

Compute the lab-frame azimuthal angle of n̂ (naz) in degrees.

naz is the azimuthal angle of the surface normal n̂ projected onto the horizontal plane of the lab frame (the plane perpendicular to the vertical axis). It describes the in-plane orientation of the sample surface relative to the lab coordinate system.

Requires surface_normal to be set.

Parameters:

  • geometry (AdHocDiffractometer) – The diffractometer instance.

  • angles (dict[str, float] or None) – Motor angles in degrees. If None, the geometry’s current stage angles are used.

Returns:

Azimuthal angle naz in degrees, in the range (−180°, +180°].

Return type:

float

Raises:

ValueError – If geometry.surface_normal is None.

References

  • You (1999).

ad_hoc_diffractometer.reference.psi_angle(geometry: AdHocDiffractometer, angles: dict[str, float] | None = None) → float[source]#

Import: ad_hoc_diffractometer.reference.psi_angle

Compute the azimuthal angle ψ of the reference vector n̂ about Q.

ψ is the angle between the azimuthal reference direction (projected onto the plane perpendicular to Q) and the incident beam direction (also projected onto that plane). ψ = 0 when the reference vector lies in the scattering plane on the same side as the incident beam.

Requires azimuthal_reference to be set.

Parameters:

  • geometry (AdHocDiffractometer) – The diffractometer instance.

  • angles (dict[str, float] or None) – Motor angles in degrees. If None, the geometry’s current stage angles are used.

Returns:

Azimuthal angle ψ in degrees, in the range (−180°, +180°].

Return type:

float

Raises:

  • ValueError – If geometry.azimuthal_reference is None.

  • ValueError – If the reference vector is parallel to Q (ψ is undefined).

References

  • You (1999), eq. 23.
