   The seven crystal systems, derived from :data:`_SYSTEM_FREE_PARAMS`.

.. py:class:: Lattice(a: float = 1.0, b: float = _UNSET, c: float = _UNSET, alpha: float = _UNSET, beta: float = _UNSET, gamma: float = _UNSET, precision: int | None = None)

   .. container:: import-path

      Import: ``ad_hoc_diffractometer.lattice.Lattice``


   A crystal lattice described by up to six parameters (a, b, c, α, β, γ).

   The crystal system is deduced automatically from the **minimum set** of
   parameters supplied.  Missing parameters are filled in according to the
   symmetry constraints of the deduced system.  The default (no arguments)
   is a cubic lattice with a = 1 Å.

   .. list-table:: Minimum parameters by crystal system
      :header-rows: 1
      :widths: 20 50

      * - System
        - Minimum parameters required
      * - Cubic
        - ``a``
      * - Tetragonal
        - ``a``, ``c``
      * - Hexagonal
        - ``a``, ``c``, ``gamma=120`` *(must be explicit)*
      * - Trigonal
        - ``a``, ``alpha`` *(alpha ≠ 90)*
      * - Orthorhombic
        - ``a``, ``b``, ``c``
      * - Monoclinic
        - ``a``, ``b``, ``c``, ``beta``
      * - Triclinic
        - ``a``, ``b``, ``c``, ``alpha``, ``beta``, ``gamma``

   All parameters are validated on construction and on every change:
     - Lengths (a, b, c) must be strictly positive.
     - Angles (alpha, beta, gamma) must be in (1, 179) degrees.
     - The combination must produce a non-degenerate unit cell.

   Cartesian lattice vectors, reciprocal lattice vectors, and the B matrix
   are computed lazily: calculated on first access and cached until any
   lattice parameter changes.

   :param a: Lattice parameter a in Angstroms.  Default 1.0.
   :type a: float, optional
   :param b: Lattice parameter b in Angstroms.
   :type b: float, optional
   :param c: Lattice parameter c in Angstroms.
   :type c: float, optional
   :param alpha: Angle between b and c axes in degrees.
   :type alpha: float, optional
   :param beta: Angle between a and c axes in degrees.
   :type beta: float, optional
   :param gamma: Angle between a and b axes in degrees.
   :type gamma: float, optional
   :param Properties (read/write):
   :param -----------------------:
   :param a:
   :type a: float — lattice parameters in Angstroms
   :param b:
   :type b: float — lattice parameters in Angstroms
   :param c:
   :type c: float — lattice parameters in Angstroms
   :param alpha:
   :type alpha: float — lattice angles in degrees
   :param beta:
   :type beta: float — lattice angles in degrees
   :param gamma:
   :type gamma: float — lattice angles in degrees
   :param precision: package-level default from display.get_precision()
   :type precision: int or None — decimal places for display; None uses the
   :param Properties (read-only:
   :param lazy):
   :param ----------------------------:
   :param system:
   :type system: str — deduced crystal system
   :param cartesian_lattice_vectors:

   .. rubric:: Examples

   >>> Lattice()                                     # cubic, a=1 Å
   >>> Lattice(a=5.0)                                # cubic, a=5 Å
   >>> Lattice(a=3.0, c=6.0)                         # tetragonal
   >>> Lattice(a=4.785, c=12.991, gamma=120.0)       # hexagonal
   >>> Lattice(a=5.0, alpha=60.0)                    # trigonal

   .. py:property:: B
      :type: ~numpy.ndarray


      B matrix in Å⁻¹ (with 2π factor, Busing & Levy 1967 / SPEC convention).

      Transforms Miller indices ``h`` = (h, k, l) to the scattering vector
      in Cartesian crystal-frame coordinates::

          Q_c = B @ h

      ``|B @ h| = 2π / d_hkl``.  The orthogonality condition is
      ``bᵢ · aⱼ = 2π δᵢⱼ``.

      This follows the Busing & Levy (1967) eq. 3 and SPEC convention.
      Some other packages (FullProf, CrysFML, hkl with ``tau=1``) use a
      no-2π variant where ``bᵢ · aⱼ = δᵢⱼ`` and ``|B @ h| = 1/d_hkl``.

      Cached until a lattice parameter changes.


   .. py:method:: _invalidate() -> None

      Mark all cached computations as stale.



   .. py:method:: _set_params(**kwargs) -> None

      Update one or more lattice parameters, re-deduce the crystal system,
      and invalidate the cache.  Parameters are always passed to the
      deduction function in the canonical order a, b, c, alpha, beta, gamma.

      All six current values are passed through, with kwargs overriding.
      This allows re-deduction across crystal systems when a parameter
      change alters the symmetry (e.g. setting b != a on a cubic lattice
      causes re-deduction to orthorhombic).

      Individual parameter validation (positive lengths, angle range) is
      performed first, before deduction, so that errors are reported with
      the correct parameter name rather than a generic deduction error.

.. py:function:: _deduce_system_and_params(a, b, c, alpha, beta, gamma) -> tuple[str, float, float, float, float, float, float]

   .. container:: import-path

      Import: ``ad_hoc_diffractometer.lattice._deduce_system_and_params``


   Deduce the crystal system from the supplied parameters and fill in
   symmetry-required defaults for any that were not supplied.

   Caller supplies values or _UNSET for each parameter.  'a' is always
   required.  All other parameters are optional; their defaults depend on
   the deduced crystal system.

   Deduction rules (most constrained first):

   Cubic:         a only
   Trigonal:      a + alpha (alpha != 90)
   Hexagonal:     a + c + gamma=120 (gamma must be explicit)
   Tetragonal:    a + c (no angles)
   Orthorhombic:  a + b + c (no angles)
   Monoclinic:    a + b + c + beta
   Triclinic:     all six

   When all six parameters are supplied, the system is classified by
   examining the symmetry of the values.

   :param a: Each is either a float (supplied) or _UNSET (not supplied).
   :param b: Each is either a float (supplied) or _UNSET (not supplied).
   :param c: Each is either a float (supplied) or _UNSET (not supplied).
   :param alpha: Each is either a float (supplied) or _UNSET (not supplied).
   :param beta: Each is either a float (supplied) or _UNSET (not supplied).
   :param gamma: Each is either a float (supplied) or _UNSET (not supplied).

   :returns: * **system** (*str*)
             * **a, b, c, alpha, beta, gamma** (*float (complete, validated)*)

   :raises ValueError: If 'a' is not supplied, if the supplied combination is ambiguous
       or inconsistent, or if validated parameters are out of range.

.. py:function:: b_matrix(b1: ~numpy.ndarray, b2: ~numpy.ndarray, b3: ~numpy.ndarray) -> ~numpy.ndarray

   .. container:: import-path

      Import: ``ad_hoc_diffractometer.lattice.b_matrix``


   Compute the B matrix from the reciprocal lattice vectors.

   The B matrix transforms Miller indices ``h`` = (h, k, l) to the
   scattering vector in Cartesian crystal-frame coordinates
   (Busing & Levy, 1967, eq. 3)::

       Q_c = B @ h

   The columns of B are the reciprocal lattice vectors b₁, b₂, b₃
   (each including the 2π factor), so::

       B = [b1, b2, b3]    (column-stack of the reciprocal vectors)

   Hence ``B @ h = h·b1 + k·b2 + l·b3``.  The orthogonality condition
   is ``bᵢ · aⱼ = 2π δᵢⱼ``, and ``|B @ h| = 2π / d_hkl``.

   This is the Busing & Levy (1967) and SPEC convention.  Some packages
   (FullProf, CrysFML, parts of CCP4, the hkl library with ``tau=1``)
   use the alternative no-2π convention ``bᵢ · aⱼ = δᵢⱼ``, which gives
   a B matrix smaller by a factor of 2π.

   :param b1: Reciprocal lattice vectors in inverse Angstroms (with 2π factor),
              as returned by :func:`reciprocal_vectors`.
   :type b1: numpy.ndarray, shape (3,)
   :param b2: Reciprocal lattice vectors in inverse Angstroms (with 2π factor),
              as returned by :func:`reciprocal_vectors`.
   :type b2: numpy.ndarray, shape (3,)
   :param b3: Reciprocal lattice vectors in inverse Angstroms (with 2π factor),
              as returned by :func:`reciprocal_vectors`.
   :type b3: numpy.ndarray, shape (3,)

   :returns: **B** -- B matrix in inverse Angstroms (with 2π factor, BL1967 convention).
   :rtype: numpy.ndarray, shape (3, 3)

.. py:function:: reciprocal_vectors(a1: ~numpy.ndarray, a2: ~numpy.ndarray, a3: ~numpy.ndarray) -> tuple[~numpy.ndarray, ~numpy.ndarray, ~numpy.ndarray]

   .. container:: import-path

      Import: ``ad_hoc_diffractometer.lattice.reciprocal_vectors``


   Compute the three reciprocal lattice vectors from Cartesian direct lattice
   vectors.

   Uses the standard crystallographic definition:

       b1 = 2*pi * (a2 x a3) / (a1 . (a2 x a3))
       b2 = 2*pi * (a3 x a1) / (a1 . (a2 x a3))
       b3 = 2*pi * (a1 x a2) / (a1 . (a2 x a3))

   The orthogonality condition is satisfied:

       b_i . a_j = 2*pi * delta_ij

   :param a1: Cartesian direct lattice vectors in Angstroms.
   :type a1: numpy.ndarray, shape (3,)
   :param a2: Cartesian direct lattice vectors in Angstroms.
   :type a2: numpy.ndarray, shape (3,)
   :param a3: Cartesian direct lattice vectors in Angstroms.
   :type a3: numpy.ndarray, shape (3,)

   :returns: **b1, b2, b3** -- Reciprocal lattice vectors in inverse Angstroms (with 2*pi factor).
   :rtype: numpy.ndarray, shape (3,)
